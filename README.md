## 🛠️ QUICK CUSTOMIZATION GUIDE
You don't need to be a senior developer to edit this website. All your personal and product data is managed in ONE single location within the JavaScript file.

### 1. Open the Data Hub
Locate and open the file: `script.js`

### 2. Edit Your Identity
Find the `VAULT_DATA` object at the top of the script. Change the text inside the quotes ` " " ` to your own details:

```javascript
const VAULT_DATA = {
    owner: {
        firstName: "FRANS",          // ✏️ Change to your First Name
        lastName: "MARCELLINO",     // ✏️ Change to your Last Name
        fullName: "FRANS MARCELLINO",
        title: "Digital Architect",  // ✏️ Your Job Title
        tagline: "Architecting Digital Sovereignty." // ✏️ Your Hero Message
    }
};

3. Update Your Digital Assets (The Repository)
To change the items you are selling or showcasing, look for the assets section in the same file:

assets: [
        {
            id: 1,
            name: "TITAN CORE V1",    // ✏️ Asset Name
            price: "$450.00",         // ✏️ Set your Price in USD
            category: "SOFTWARE",     // ✏️ Category Label
            description: "Industrial-grade software engine."
        },
        // Add more items here following the same format!
    ]

4. Connect Your Social Media
Update your contact links so clients can reach you:
